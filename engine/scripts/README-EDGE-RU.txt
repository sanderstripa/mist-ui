MIST Edge — обновление сервера
================================

ЭТА ПАПКА НЕ ЗАПУСКАЕТСЯ В WINDOWS.
Она предназначена для Linux VPS, на котором уже установлен MIST Edge.

Если MIST Edge уже работает на сервере:

1. Скопируй всю эту папку на VPS.
2. Подключись к VPS по SSH.
3. Перейди в загруженную папку.
4. Выполни:

   chmod +x UPDATE-MIST-EDGE.sh
   sudo ./UPDATE-MIST-EDGE.sh

Скрипт сам:
- найдёт systemd-сервис MIST Edge;
- найдёт установленный бинарник из ExecStart;
- сохранит текущий /etc/mist/server.json;
- создаст резервную копию старого бинарника;
- заменит только бинарник Edge;
- перезапустит сервис;
- проверит, что сервис остался active;
- запустит verify-edge.sh;
- при неудачном старте автоматически вернёт старый бинарник.

ВАЖНО:
- server.example.json — только пример. Он НЕ заменяет рабочий /etc/mist/server.json.
- Для обычного обновления не нужно повторно устанавливать сервер и не нужно заново создавать сертификаты/токены.
- Резервные копии сохраняются в /var/backups/mist/<дата-время>/.

Если сервис называется не mist-edge.service и не mist.service:

   MIST_SERVICE=имя.service sudo ./UPDATE-MIST-EDGE.sh

Если бинарник установлен в нестандартном месте и скрипт не смог определить путь:

   MIST_TARGET=/полный/путь/к/mist-edge sudo ./UPDATE-MIST-EDGE.sh

Файл BUILD.txt в этой папке показывает commit, из которого собран конкретный архив.
