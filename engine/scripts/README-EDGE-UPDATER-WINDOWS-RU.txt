MIST Edge Updater for Windows

Как обновить сервер:

1. Полностью распакуй этот ZIP в отдельную папку.
2. Дважды кликни UPDATE-MIST-EDGE-WINDOWS.cmd.
3. При первом запуске введи IP или hostname VPS. Он сохранится в MIST-SERVER.txt рядом с батником.
4. Один раз введи SSH-пароль root, когда его запросит Windows OpenSSH.
5. Дождись сообщения [OK] MIST Edge updated successfully.

Дальше, пока VPS тот же, батник уже помнит адрес сервера: запускаешь его и вводишь только пароль.

Что происходит автоматически:
- пакет обновления передаётся на VPS в том же SSH-сеансе;
- текущий server.json не заменяется;
- сертификаты и токены не заменяются;
- старый бинарник и конфиг сохраняются в /var/backups/mist/<дата>/;
- systemd-сервис перезапускается;
- выполняется проверка живого Edge;
- если новый бинарник не стартует, серверный updater пытается вернуть предыдущий.

Для обычного обновления НЕ нужно вручную открывать SSH, копировать файлы или вводить Linux-команды.

Требование: Windows OpenSSH Client. В Windows 10/11 обычно он уже установлен.

Если сменился VPS, удали MIST-SERVER.txt и запусти батник снова — он спросит новый адрес.
